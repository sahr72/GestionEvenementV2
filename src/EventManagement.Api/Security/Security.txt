Lecture du mapping : Administrator et Organizer portent les mêmes permissions. 
Ce qui les distingue n'est pas le jeton de permission, mais le bypass ressource IsInRole("Administrator") (voir §1.3). 
Les rôles ne sont donc pas trois ensembles de permissions disjoints : ce sont des personas dont la différence se joue 
à deux endroits précis (permissions + bypass ressource).

Codes de statut :
401 = authentification absente/invalide (ou identité inexploitable dans le jeton)
403 = authentifié mais autorisation insuffisante (permission OU ressource)
404 = ressource inexistante
409 = ressource existante mais opération incompatible avec l'état métier
